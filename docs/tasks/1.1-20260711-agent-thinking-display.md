```ts
export interface StreamThinkingChunkEvent {
```

### T3 — 修订 AnthropicProvider SSE 解析器

**文件：** `src/agent/provider/impl/anthropic.ts`

**依赖：** T1（`StreamChunk.thinkingDelta` 类型需已定义）

**要做什么：**
- 在 `parseAnthropicStream()` 内部新增 `activeBlockType` 状态变量，并附注释说明顺序假设：

```ts
// 注意：当前实现假设 Anthropic SSE 中各 content block 严格顺序，
// 不存在交错（即 block_N_stop 一定先于 block_N+1_start）。
// 若 Anthropic 将来支持并发 block，需改为 Map<index, type>。
let activeBlockType: "text" | "thinking" | null = null
```

- 修订 `content_block_start` 事件处理：读取 `content_block.type` 字段，为 `"thinking"` 时将 `activeBlockType` 置为 `"thinking"`，否则置为 `"text"`（替换原来直接 `break` 的逻辑）
- 修订 `content_block_delta` 事件处理：根据 `activeBlockType` 分支：
  - `"thinking"`：提取 `delta.delta?.thinking`，非空时 yield `{ delta: "", done: false, thinkingDelta: thinking }`
  - 其他（`"text"` 或 `null`）：原有逻辑不变，提取 `delta.delta?.text`，非空时 yield `{ delta: text, done: false }`
- 新增 `content_block_stop` 事件处理：将 `activeBlockType` 置为 `null`

**预期结果：** 含 thinking block 的 SSE 流产出带 `thinkingDelta` 的 chunk；不含 thinking block 的普通流产出与修改前完全相同的 chunk 序列（向后兼容）；`bunx tsc --noEmit` 通过。

### T5 — 扩展 AgentRunner 核心循环（thinking 累积与 abort 处理）

**文件：** `src/agent/runner.ts`

**依赖：** T1、T2、Spec 2 实现完成（`runner.ts` 已存在）

**要做什么：**
- 在核心循环内新增 `accumulatedThinking: string` 累积变量（与已有的 `accumulatedText` 并列），每轮 `send()` 开始时初始化为 `""`
- 修订 chunk 处理分支（对应 Spec 1.1 §7）：
  - 收到含非空 `thinkingDelta` 的 chunk 时：emit `stream_thinking_chunk { delta: thinkingDelta, messageId: replyId }`，并追加到 `accumulatedThinking`
  - `delta` 非空时才 emit `stream_chunk`（修订原来无条件 emit 的逻辑，空 delta 不透传）
  - `done === true` 时：若 `accumulatedThinking` 非空，先 emit `stream_thinking_done { totalThinking: accumulatedThinking, messageId: replyId }`，再 emit `stream_done`（原有逻辑不变）
- 修订 AbortError 处理分支：若 `accumulatedThinking` 非空，先 emit `stream_thinking_done`（携带部分 thinking），再 emit `agent_abort`，保证 UI 端 `isThinkingStreaming` 正常归零

**预期结果：** `AgentRunner` 在含 thinking 的流中按序 emit `stream_thinking_chunk` → `stream_thinking_done` → `stream_done`；abort 时 `stream_thinking_done` 先于 `agent_abort`；`bunx tsc --noEmit` 通过。

### T6 — 实现 ThinkingBlock 组件

**依赖：** Spec 4 实现完成（`@opentui/react` 基础组件可用），T2（`AgentEvent` 类型已定义）


- streaming 完成后：折叠态显示字数提示，格式 `(N chars)`，`fg: overlay0, dim`

**预期结果：** `ThinkingBlock` 组件可独立渲染，折叠/展开切换正确，streaming 进行中显示 loading 动画，完成后显示字数；`bunx tsc --noEmit` 通过。

### T7 — 修订 MessageItem 与 messages 区 `t` 键处理

**文件：**
- `src/components/MessageItem.tsx`（修改，依赖 Spec 4 实现）
- `src/components/MessageArea.tsx`（修改，依赖 Spec 4 实现）

**依赖：** T6、Spec 4 实现完成

**要做什么：**
- **`MessageItem.tsx`**：在 `MessageHeader` 与 `MessageBody` 之间条件渲染 `ThinkingBlock`——仅当 `message.thinking || message.streamingThinking` 存在且外部传入的 `showThinking !== false` 时渲染；将 `message.isThinkingExpanded ?? false` 作为 `isExpanded` props，`onToggle` 回调由父组件（`MessageArea`）传入
- **`MessageArea.tsx`**：
  - 在消息列表 state 中，每条 `ChatMessage` 的 `isThinkingExpanded` 默认初始化为 `false`（或省略，消费时用 `?? false`）
  - 订阅 `stream_thinking_chunk` 事件：找到对应 `messageId` 的消息，追加 `streamingThinking`，将 `isThinkingStreaming` 置为 `true`
  - 订阅 `stream_thinking_done` 事件：找到对应 `messageId` 的消息，写入 `thinking`，清空 `streamingThinking`，将 `isThinkingStreaming` 置为 `false`
  - 在 `messages` 焦点区绑定 `t` 键处理器：找到消息列表中**最后一条 `role === "assistant"` 且 `thinking` 字段非空**的消息，切换其 `isThinkingExpanded` 状态；若无此消息则无操作
  - 从 `PawSettings`（或通过 props/context 传入）读取 `showThinking` 值，传递给 `MessageItem`

**预期结果：** 助手消息在含 thinking 时在正文前渲染 `ThinkingBlock`；`t` 键正确展开/折叠最后一条含 thinking 的助手消息；`showThinking: false` 时 `ThinkingBlock` 不渲染；`bunx tsc --noEmit` 通过。
